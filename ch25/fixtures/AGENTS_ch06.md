# AGENTS.md: claims context platform

## Commands
- Run the tests: `pytest` from the repository root. All tests must pass before a change is proposed.
- Run a chapter lab: `python chNN/lab.py`. Each lab rewrites its own output.txt and CSV files.

## Never
- Never edit files under fixtures/data by hand. They are generated by fixtures/generate.py.
- Never edit chNN/instructions_v*.md by hand. They are rendered from contextlab/instructions.py.
- Never change the 200-claim evaluation set or the hold-out. They are frozen.

## Know
- All policyholder names and claims in fixtures are synthetic.
- The claims assistant's runtime instructions live in contextlab/instructions.py, not in this file.
  Nothing in this file reaches the claims assistant.

## Owners
- contextlab/instructions.py and this file: two reviewers from the claims AI team (see CODEOWNERS).
